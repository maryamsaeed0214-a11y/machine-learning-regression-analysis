# machine-learning-regression-analysis
This project demonstrates the implementation and comparison of multiple machine learning regression models using Python and Scikit-learn. It includes data preprocessing, feature engineering, model training, and performance evaluation using Linear Regression, Polynomial Regression, Ridge Regression, and Lasso Regression.
# Machine Learning Regression Analysis using Python

## 📌 Project Overview

This project demonstrates the implementation and comparison of multiple regression models using Python and Scikit-learn. It covers the complete machine learning workflow, including dataset preparation, data preprocessing, model training, and performance evaluation.

---

## 🎯 Objectives

- Generate and prepare a sample dataset
- Clean and preprocess the data
- Handle missing values and duplicate records
- Encode categorical variables
- Train multiple regression models
- Compare model performance using evaluation metrics

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

---

## 📂 Workflow

1. Dataset Generation
2. Data Cleaning
3. Data Preprocessing
4. Feature Encoding
5. Train-Test Split
6. Linear Regression
7. Polynomial Regression
8. Ridge Regression
9. Lasso Regression
10. Model Evaluation

---

## 🤖 Regression Models

- Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression

---

## 📊 Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score

---

## 📈 Results

The project compares the performance of multiple regression models using standard evaluation metrics and summarizes their results in a comparison table.
